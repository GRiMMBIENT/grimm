CONNECT

Connect the FM-1 with a USB data cable, switch it on with GR!MM, close other apps that use its MIDI port, then click CONNECT and allow MIDI (SysEx) when the browser asks. Chrome or Edge on a computer. TRY WITHOUT AN FM-1 runs GR!MM's own code in this page instead: everything works, nothing is kept.

The FM-1 only accepts writes while it is stopped and silent: stop the sequencer and let every note, release and DELAY or SPACE tail end. Nothing is ever written without you clicking a button.

GR!MM 2.0 adds FX, SETTINGS (MIDI CHANNEL's CH n > SEL, CLOCK, LATCH) and the samples in a backup; an FM-1 with GR!MM 1.0 doesn't answer those (update it on the FM-1 Firmware Hub), the rest works.

EMPTY

      

      

      

      

      
The four tracks' patterns, as the FM-1's SEQ pages: pick a step, then set its NOTE (0 is OFF), CHANCE,
        RATCHET, LENGTH, a chord step, and its locks (a lock replaces one of the track's four knobs on that step; move
        a slider to lock it, untick to free it). In the grid, C marks a chord step, L a step with locks; dim steps are
        after the track's last step. IMPORT SLOT reads a slot, IMPORT: PLAYING NOW what the FM-1 plays at this moment.
        SEND TO SLOT first downloads a backup of the slot, then changes only its patterns (the sounds and mix stay),
        reads it back and checks it; it is refused while the FM-1 plays or still sounds. Then, on the FM-1, hold SAVE + F3
        (A), G3 (B), A3 (C) or B3 (D) to recall it. PREVIEW plays the patterns in this page's GR!MM, with the sounds of
        T1–T4 as the SOUND EDITOR has them. SAVE FILE and LOAD FILE keep the patterns on this computer.

      
STEP RECORD: press REC, then play: a MIDI keyboard (pick it under MIDI IN; the FM-1's own port is not
        listed), or the computer's keys A W S E D F T G Y H U J K (one octave, Z and X move it). Each note goes into the
        selected step and the cursor moves on, wrapping at the track's last step. REST, the sustain pedal (CC64) and Space
        skip a step; TIE makes the step before one longer; Backspace clears the step; the arrow keys move the cursor. Three
        or more keys pressed together that are one of the FM-1's chords (CHORD TYPE and VOICING, SCALE aside) make a chord
        step; any other chord writes its lowest note. MONITOR plays what you press in this page's GR!MM.

    


    

      
SAMPLES

      

        

      

      
Any WAV (8 to 32 bit, float, mono or stereo, any rate) becomes mono, 22050 Hz, IMA ADPCM, as
        tools/fm1_sample_upload.py makes it; GR!MM 2.0's encoder no longer clicks on bright samples. A slot holds 6.64 s
        (longer: cut, with a short fade). The root note is C4 unless the file name has one ("drone_A2.wav"). A name is
        8 characters (the slot's, what the FM-1 shows): a longer one keeps its number ("Sample-002": SAMP-002).

      
NORMALISE (switched on as the page opens) brings every WAV to the same loudness; switched off, a
        sample keeps its own level (quiet ones stay quiet, as recorded). RESTORE FACTORY SAMPLES writes GR!MM's four
        (URCHIN, LEAVE, NIKOLAI, M-SOFT) over all four slots; an FM-1 also gets them by itself at power-on in a slot
        that holds nothing. A BACKUP holds the four slots too.

    


    

      
FX

      

      

      
The project's effects, as the FX pages on the FM-1 (TAPE, GRAIN, DELAY, SPACE, MASTER, DRIVE), and
        each track's filter TYPE and POS (MIXER 2) and its five sends (MIXER 1). READ first; then every move reaches the FM-1 at once, as its knobs
        (kept with the project: its autosave). The FM-1's own knobs and this page don't follow each other: READ again
        after turning them. MASTER, DRIVE, the filter's TYPE and POS and the TAPE and DRIVE sends are GR!MM V2's.

    


    

      
SETTINGS

      

      

      

      

      

      
The FM-1's own settings (SYSTEM, SYSTEM 2, SYSTEM 3), not the project's. MIDI CHANNEL: 1-4 puts T1–T4 on
        channels 1–4 (up to 13-16); ALL > SEL plays every channel on the selected track; CH n > SEL plays only
        channel n on the selected track and ignores the others. CLOCK: INT, the FM-1's own tempo; INT+OUT, the same
        and its MIDI clock out over USB (START, STOP and 24 pulses a beat); USB or TRS, it follows the MIDI clock from
        there (START, CONTINUE, STOP; the jack is MIDI IN only). LATCH: FROM SOUND, a sound you load brings its own
        LATCH (as GR!MM 1.0); ALWAYS OFF, a sound you load sets the track's LATCH off (you can still latch it by hand:
        EDIT's LATCH, SEL + OCT+). The same on the FM-1: SYSTEM's KNOB 2, SYSTEM 2's KNOB 4, SYSTEM 3's
        KNOB 1. READ first; WRITE changes only these three (the FM-1 stopped and silent). GR!MM 1.0 has no CLOCK, and
        no LATCH setting.

    


    

      
BACKUP

      

        
        
        
      

      
A backup holds all 64 user sounds, slots A–D, the settings and the four sample slots (the same
        file as tools/fm1_editor_test.py makes). Restoring first makes a backup of what the FM-1 has now (downloaded),
        then writes everything, then reads it back to check; a sample slot that already holds the same sample is not
        written again, one empty in the backup is emptied. An older backup (GR!MM 1.0's, without samples) restores the
        rest and leaves the sample slots as they are.
